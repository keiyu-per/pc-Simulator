# シミュレーター占い　初版仕様書

2026-11-18 ｜ v0.1 ｜ 要件定義

## 1. 目的と利用の流れ

今日の星座占い・名前の画数占いを見てから、好きなパチンコ実機を選び、「規定回数の当たりを引くまでに何回転かかり、何発出るか」を抽選する。その引き方から今日の運勢を表示する。

**合意済みの要件**は、画面最上部の2種類の占い、以下の4機種、所定の当たり回数までの抽選、回転数・出玉の記録、結果に応じた運勢表示。以下で「初版案」と記す内容は、開発を進めるための仮定として扱う。

## 2. 画面と操作

| 順番 | 内容 | 表示・操作 |
|---|---|---|
| 1 | 今日の星座占い | 日本時間の日付、星座、今日の運勢、取得元。初回は星座を選択する。 |
| 2 | 名前の画数占い | 入力した名前、画数、鑑定結果。名前と算定方式が同じ間は同じ結果を表示する。 |
| 3 | シミュレーター占い | 実機名と通常時の確率を表示し、1機種と目標回数を選んで「占う」を押す。 |
| 4 | 結果と履歴 | 今日の判定、目標到達までの回転数、合計払出玉数を先頭に表示。各当たりの内訳を開いて確認できる。 |

初版案はスマートフォン向けの縦一列表示。占いデータの未取得、名前の未入力時にもシミュレーションは遊べる。星座占いは日付と星座をキーに取得済み結果を再利用する。取得に失敗した日は当日分が未取得と表示し、再試行できる。画数占いは対応外の漢字を明示し、字を飛ばして合計しない。

## 4. 抽選と終了条件（初版案）

1. 目標は初当たり1・3・5回から選ぶ。通常状態での図柄当たりを1回とし、東京喰種のチャージは履歴・出玉に記録する。チャージのみで終われば目標は進めず、チャージからRUSHへ昇格した場合は初当たり1回とする。
2. 右打ち中の当たり・上乗せは連チャン履歴と出玉に加える。目標の初当たり数には加えない。
3. 「目標到達回転数」は、目標の初当たりを引いた時点までの累計通常回転数とする。右打ちで消化した回転数は別集計する。
4. 最後の初当たりに伴うRUSH・残保留・上乗せも最後まで消化し、そこで合計払出玉数を確定する。出玉の単位は全画面で「払出○発」とし、投資や差玉は計算しない。

例：目標が初当たり3回で、通常時の当たり間隔が80・120・40回転なら、到達は240回転。1回目のRUSHで2回当たっても、その時点の進捗は1/3。3回目から続いた連チャンの払出も結果に含める。

## 5. シミュレーター占いの判定（初版案）

同じ機種・目標回数・モデル版のシミュレーションを基準に、初当たりの早さと合計出玉をそれぞれ百分位で評価する。早いほど、また出玉が多いほど高得点。同値は同順位の中央で評価し、2項目を等しい重みで平均する。総合点が80以上なら大吉、60以上なら吉、40以上なら中吉、20以上なら小吉、それ以外は末吉。例として「初当たりが早く、出玉も同条件の上位20%」のように結果に基づく一言を添える。境界値や名称は調整可能とする。

同じ日本時間の日付・端末・機種・目標回数で再表示した場合は保存済みの結果を表示する。他の機種や目標は個別に占える。抽選・玉数計算・順位判定はコードで再現可能にし、AI駆動開発でも抽選結果を文章生成に委ねない。

## 6. 保存と検証（初版案）

- 端末内に星座・名前と実戦履歴を保存。各実戦に日付、機種ID、モデル版、目標、抽選シード、判定版、通常回転数、右打ち回転数、合計払出玉数、運勢を持たせる。
- 当たり履歴は順序、通常／右打ち、当たり種別、区間回転数、累計通常回転数、払出玉数、移行先を記録する。内訳の払出合計と結果画面の合計が一致すること。
- 同一シード・同一設定・同一モデル版では履歴が一致すること。目標1回・RUSH非突入、最終初当たりからの連チャン、チャージのみ、チャージ昇格、残保留引き戻しを該当機種ごとに検証する。
- 日本時間の午前0時をまたぐと新しい日の結果を扱う。星座占いの取得失敗や名前の未入力が、他のカードの表示・抽選を妨げないこと。

## 7. 実装前に決めること

| 確認項目 | 選択による影響 |
|---|---|
| 目標の「当たり」は初当たり限定か、右打ちを含む全当たりか | 全当たり方式なら終了条件と運勢の比較基準を変更する。 |
| 星座占いの提供元と取得方式 | 当日分の更新時刻、利用可能な表示項目、転載・出典表示条件を確認する。 |
| 名前の鑑定方式 | 姓名全体／名前のみ、新字体／旧字体、総画のみ／五格を選び、使用する画数辞書と鑑定文の出典を決める。 |
| 日ごとの再抽選と判定の好み | 初版案は同条件で1日1結果。回転数と出玉を等しく評価する。 |
